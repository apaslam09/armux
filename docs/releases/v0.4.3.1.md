armux 0.4.3.1 is a bug-fix release: armux no longer crashes at start-up or when you resize the window at zoom levels such as 120%.

## Install

1. Download `armux-0.4.3.1-win-arm64.zip` below and extract it anywhere, for example `%LOCALAPPDATA%\Programs\armux`. To upgrade, close armux and replace the old files.
2. Run `armux.exe`.

You need Windows 11 on ARM64 with the Windows App Runtime 1.8 and the WebView2 Runtime (both are usually already installed).

## Fixed

- **Crash at start-up and on resize with app zoom set to 120% (also seen at 150%).** The window failed with a layout-cycle error and closed. The zoom code now skips size changes that do nothing and does its window-size work after layout finishes.
