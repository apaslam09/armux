armux 0.4.2 stops Claude Code from running to the top when you scroll a little too fast, makes shortcuts work wherever the keyboard is, keeps typing on the Settings page out of the terminal, and redraws every menu and popup in the style of the rest of the app.

## Install

1. Download `armux-0.4.2-win-arm64.zip` below and extract it anywhere, for example `%LOCALAPPDATA%\Programs\armux`. To upgrade, close armux and replace the old files.
2. Run `armux.exe`.

You need Windows 11 on ARM64 with the Windows App Runtime 1.8 and the WebView2 Runtime (both are usually already installed).

## Fixed

- **Scrolling in Claude Code.** A slightly fast wheel or a touchpad flick ran the conversation to the top. Claude Code speeds up when wheel events arrive close together, so armux now sends them in small batches at a steady pace and drops what doesn't fit, and scrolling stops when your fingers stop. In real Claude Code, 6 quick notches moved more than a screen before and move about 12 rows now; a single notch still moves 3 rows. This applies to every program that tracks the mouse. armux's own scrollback is unchanged.
- **Shortcuts wherever the keyboard is.** armux's shortcuts now act before any control sees the key, so they work whichever part of the window has focus, or if nothing does. Keys armux doesn't use still go to the program in the terminal. In browser tabs they also work inside iframes.
- **Typing on the Settings page** went into the terminal behind it. The page now takes the keyboard when it opens, and the terminal gets it back when it closes. Up and Down scroll the page.
- **Memory after popups.** Each popup, dialog and Settings page left memory behind until a garbage collection, which an idle app may not run for a long time. After 100 popups, private bytes are 51.2 MB, down from 102.0 MB, and they no longer grow with more.

## Changed

- **Menus and popups** have armux's own look instead of WinUI's square one: rounded corners, compact rows and the shortcut on the right, for workspace, terminal and explorer menus, Settings dropdowns, and the color and notification popups. Use Up, Down and Enter in a menu; Esc or a click outside closes it. A workspace's menu opens at the pointer, and popups follow the window's zoom.

## Not covered

- Shortcuts typed in a frame inside a frame, or on pages that run no script (Chromium's error pages and PDF viewer), stay with the page. Click the address bar or another part of the window first.

## Memory

Measured on a Surface Laptop 7 (Snapdragon X Plus), one PowerShell pane, armux plus its conhost, average of 3 runs (working set / private bytes / Task Manager memory):

| Version | Memory |
|---|---|
| 0.4.2 | 111.2 / 50.2 / 29.0 MB |
| 0.4.1 (same session) | 112.0 / 50.1 / 29.0 MB |

After opening and closing 100 popups, armux alone: 106.6 / 51.2 / 30.9 MB, down from 150.7 / 102.0 / 72.9 MB in 0.4.1.
