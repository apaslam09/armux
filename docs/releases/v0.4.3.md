armux 0.4.3 brings back the prompt editor, which 0.4.2 broke, makes Shift+Enter start a new line in Claude Code, and fixes shortcuts that stopped working while a tooltip was showing.

## Install

1. Download `armux-0.4.3-win-arm64.zip` below and extract it anywhere, for example `%LOCALAPPDATA%\Programs\armux`. To upgrade, close armux and replace the old files.
2. Run `armux.exe`.

You need Windows 11 on ARM64 with the Windows App Runtime 1.8 and the WebView2 Runtime (both are usually already installed).

## Fixed

- **Prompt editor (`Ctrl+G`).** In 0.4.2 the box under the terminal failed to open. The key then went to the program in the terminal, so Claude Code opened its own external editor (Notepad) instead.
- **Shift+Enter in Claude Code** now starts a new line in its prompt box instead of sending the prompt. This applies to full-screen programs; at a shell prompt Shift+Enter still runs the line.
- **Shortcuts under a tooltip.** While a tooltip was showing, armux's shortcuts did nothing.
- **Failed shortcuts.** If a shortcut ever fails, its key no longer goes on to the program in the terminal. The error goes to `armux.log`.
