armux 0.4.0 brings a new Settings page modeled on Zed's, an explorer that can browse your whole PC, workspaces that come back when you restart, and an orange light when an agent is waiting for you.

## Install

1. Download `armux-0.4.0-win-arm64.zip` below and extract it anywhere, for example `%LOCALAPPDATA%\Programs\armux`. To upgrade, close armux and replace the old files.
2. Run `armux.exe`.

You need Windows 11 on ARM64 with the Windows App Runtime 1.8 and the WebView2 Runtime (both are usually already installed). Settings stay in `%LOCALAPPDATA%\armux\settings.json`, and the saved workspaces go in `session.json` beside it.

## New

- **Workspaces reopen on start.** When armux closes, it saves your workspaces (names, colors, pins), splits and tabs. On the next start they come back, and each terminal opens in the folder it was last in.
  - It saves on close and every 30 seconds, so a shutdown or sign-out loses little.
  - Programs that were running don't restart. Run `claude --continue` to pick up a Claude Code conversation.
  - Turn it off in Settings › General › Reopen workspaces.
- **Orange light when an agent waits for you.** When Claude Code (or any program) rings the bell or sends a notification for a question or a permission prompt, the pane ring, the tab dot and the workspace's status turn orange ("Waiting for you · Claude Code"). It stays orange until you type in that terminal, even after you've read the notification. Unread notifications are still blue.
- **Zed-style Settings page.**
  - A search box finds any setting across all sections, plus matching shortcuts.
  - Flat rows, menu dropdowns and armux's own accent color replace the Windows 10 look.
  - The page now covers the whole window. The title bar shows only "Settings", so you can't open workspaces from behind it.
- **Edit settings.json in armux.** "Edit in settings.json" (or `Ctrl+Shift+,`) opens the file as an editable tab.
  - `Ctrl+S` checks the JSON, saves it and applies it immediately. If the JSON is invalid, armux shows the error with its line number and changes nothing.
  - The file is watched, so saving it in VS Code or Notepad applies at once too.
  - Comments and trailing commas are allowed.
- **Explorer browses anywhere.**
  - Go up a folder (button or Backspace) or type or paste any path into the path box (`~` works).
  - A places menu has Home, Desktop, Documents, Downloads, your OneDrive folders and every drive.
  - Double-click a folder to open it. The terminal button returns to the terminal's folder.
  - "Insert path in terminal" in the right-click menu now works.
- **Relative paths when you drag.** Dragging a file or folder onto a terminal types its path relative to that terminal's folder, now also outside it (`..\notes.md`, up to three levels). Anything further away, or on another drive, gets the full path.
- **Familiar shortcuts.**

  | Action | Shortcut |
  |---|---|
  | Settings | `Ctrl+,` (was `Ctrl+Shift+,`) |
  | Open settings.json | `Ctrl+Shift+,` |
  | Copy / paste | `Ctrl+Insert` / `Shift+Insert` (also `Ctrl+Shift+C` / `Ctrl+Shift+V`) |
  | Scroll the terminal | `Ctrl+Shift+Up` / `Down`, `Ctrl+Shift+PageUp` / `PageDown`, `Ctrl+Shift+Home` / `End` |
  | Split right / down / along the longer side | `Alt+Shift+=` / `Alt+Shift+-` / `Alt+Shift+D` |
  | Full screen | `F11` |

  These are Windows Terminal's defaults; `Ctrl+,` is VS Code's too. Every command can still be rebound in Settings › Keyboard.

## Changed

- **Prompt editor (`Ctrl+G`):** `Enter` sends, `Shift+Enter` starts a new line, and `Ctrl+Enter` pastes into the terminal without pressing Enter. The "Insert" button is now "Paste".
- **Prompt editor placeholder:** it stays gray when you click into the box. It used to turn almost black. The Paste and Send buttons and the box are rounded like the rest of armux.
- **Dialogs** (close confirmation, rename, workspace color, reset, new file) are armux's own now: rounded, in the theme's colors, with a blue main button instead of the old square Windows 10 style. Enter confirms and Esc cancels.
- **Browser address bar:** slimmer, with centered text, and it keeps its dark colors and a full blue outline when focused instead of turning white.
- **Default search engine:** Google (it was Bing). Your saved choice is kept.

## Fixed

- Changing the theme or the interface font could close armux at once (0xC000027B).
- A focused text box's blue outline was cut off along the bottom.

## Memory

For one PowerShell pane on a Surface Laptop 7, armux and its ConPTY host use about 110 MB working set, 52 MB private and 29 MB in Task Manager (0.3.0 measured 106 / 48 / 27 MB). The shell is counted separately: pwsh uses about 26 MB private. Saving the session is a small JSON write, made only when something changed. [ARCHITECTURE.md](https://github.com/apaslam09/armux/blob/main/ARCHITECTURE.md#7-memory-budget) has every scenario.

## Not yet

- Find in the terminal (`Ctrl+Shift+F` is kept free for it).
- WSL: a WSL VM costs far more memory than armux.
- An installer, and automatic updates.
